# Run App Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a one-command macOS launcher for the local app and a Cloudflare quick tunnel.

**Architecture:** A root Bash script owns both child processes and their cleanup lifecycle. A shell integration test replaces external commands through `PATH` and verifies URLs, arguments, and Ctrl-C cleanup without opening a real tunnel.

**Tech Stack:** Bash, pnpm/Vite, cloudflared, macOS networking tools.

## Global Constraints

- Run the app on `0.0.0.0:9090`.
- Print LAN and Cloudflare URLs.
- Ctrl-C must stop both child processes.
- Preserve unrelated working-tree changes.
